The Service is a free, browser-native developer toolkit that converts raster images into more than sixty machine-readable representations — including but not limited to binary bit streams, hexadecimal dumps, octal arrays, byte arrays, Uint8Array, Int16Array, Int32Array, Float32Array, Base64, Base32, Base85, Data URL, URL Encoded, ASCII text, UTF-8 text, JSON, RGB matrices, RGBA matrices, Grayscale matrices, HSL, HSV, CMYK, YUV, LAB color data, Color Histograms, C arrays, C++ arrays, Python bytes, Java byte arrays, Go slices, Rust arrays, JavaScript Buffers, PHP binary strings, Swift Data, Kotlin ByteArray, ASCII art, Braille art, Block art, Emoji art, Pixel Grid, Heatmap, MD5, SHA-1, SHA-256, CRC32, Run Length Encoding, Delta encoded pixels, NumPy arrays, TensorFlow tensors, CSV pixel data, Pandas DataFrames, Feature Vectors, SVG traces, CSS Data URIs and Canvas ImageData. The Service also reconstructs grayscale images from any of those representations. All processing runs locally inside your browser using the HTML5 Canvas API and the Web Crypto API. No image data is uploaded to any server.
