Changelog

A manually maintained record of every significant release, converter addition, revert-engine improvement, UI change, accessibility fix and bug correction shipped to Universal Image Data Explorer Forge.

🚀 v2.0 Current 🧩 Modular ES 🎨 Matrix Theme 📱 Fully Responsive

How to Read This Changelog

Every release is tagged with a semantic version number (major.minor.patch), a release date, and a short summary of what changed. Major version bumps indicate significant new functionality or breaking changes in output format. Minor version bumps indicate new converters, new pages or new download formats. Patch version bumps indicate bug fixes, performance improvements, accessibility patches and documentation corrections. The page is maintained manually — automated SEO content generation does not touch this file — so every entry here reflects a deliberate change shipped to production.

Release History

v2.0.0 — September 2026

Full 60+ Converter Engine + Revert System

  • Rebuilt the entire conversion pipeline around a canonical grayscale array computed with the ITU-R BT.601 luminance formula, guaranteeing byte-for-byte reproducibility across browsers.
  • Shipped all eight converter families: Binary / Low Level Data, Encoding Formats, Pixel Data Formats, Programming Languages, Visualization Formats, Compression / Security, AI / Data Science, Web / Browser.
  • Added the Revert Any Format → Image card supporting binary, hex, Base64, byte array, C array, Python bytes and JSON array inputs.
  • Introduced the (i) info-icon system with 200–300 word descriptions for every individual converter.
  • Added matrix-green output console with inset glow and text-shadow.
  • Added email-unlock download system producing .txt, .c, .py, .java, .js and raw .bin files.
  • Added System Logs panel with timestamped entries for every conversion and revert operation.
  • Added Web Crypto API integration for MD5, SHA-1 and SHA-256, plus table-free CRC32 implementation.
  • Added color-space converters: RGB, RGBA, Grayscale, HSL, HSV, CMYK, YUV, LAB, Color Histogram.
  • Added programming-language converters for C, C++, Python, Java, Go, Rust, JavaScript, PHP, Swift and Kotlin.
  • Added visualization converters: ASCII Art, Braille Art, Block Art, Emoji Art, Pixel Grid, Heatmap.
  • Added AI converters: NumPy Array, TensorFlow Tensor, CSV Pixel Data, Pandas DataFrame, Feature Vector.
  • Added web converters: SVG Trace, CSS Data URI, Canvas ImageData.
  • Added JSON-LD structured data for SoftwareApplication, FAQPage, HowTo and BreadcrumbList.
  • Added eight fully responsive breakpoints (1280, 1024, 900, 768, 600, 480, 360 px plus landscape).
  • Added accessibility features: :focus-visible outlines, reduced-motion support, high-contrast mode and print styles.
v1.5.0 — August 2026

Security, Color-Space and AI Families

  • Added the entire Compression / Security family (RLE, Delta, MD5, SHA-1, SHA-256, CRC32).
  • Added the entire Pixel Data family (RGB, RGBA, Grayscale, HSL, HSV, CMYK, YUV, LAB, Histogram).
  • Added the entire AI / Data Science family (NumPy, TensorFlow, CSV, Pandas, Feature Vector).
  • Added hex and octal converters alongside the original binary converter.
  • Fixed a bug where the Byte Array output included trailing commas.
  • Improved grayscale precision by switching from a naive average to the ITU-R BT.601 weighted formula.
v1.2.0 — July 2026

Encoding and Programming Families

  • Added Base64, Base32, Base85, Data URL, URL Encoded, ASCII Text, UTF-8 Text and JSON Data converters.
  • Added C, C++ and Python source-array output with copy-paste ready syntax.
  • Added the downloadable file formats .txt, .c, .py, .java, .js and raw .bin.
  • Introduced the email-unlock gate for download features.
  • Added the first version of the System Logs panel.
v1.0.0 — July 2026

Initial Public Release

  • First public launch of the Forge with binary, hex, Base64, RGB matrix, C array and ASCII art converters.
  • Drag-and-drop image upload zone with preview.
  • Basic Revert card supporting binary and hex input.
  • Simple two-column dashboard layout.
Ongoing Maintenance

Continuous Improvements

  • Bug fixes and output-format corrections.
  • Browser compatibility patches (Chrome, Firefox, Safari, Edge).
  • Performance tuning on matrix-style converters for large images.
  • Documentation corrections across all pages.
  • Accessibility improvements informed by user feedback.
  • Mobile responsiveness adjustments for new device widths.

Changelog Policy

This page records significant user-facing changes rather than every internal code commit. Minor refactors, comment updates and dependency bumps that do not affect behaviour may not appear here. The changelog is intentionally different from an automated blog feed — automated content generation tools should not overwrite this page, because the version history is a legal and trust signal for users evaluating the tool.

Found a regression? If a converter that worked in a previous version now produces incorrect output, please email support@startknowledge.in with the version number, converter name and a short description. Regressions are treated as high-priority bugs.
